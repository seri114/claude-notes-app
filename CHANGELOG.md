# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-02-07

### Added
- Initial release of claude-notes-app plugin
- Create notes from Markdown content
- Read notes and convert to Markdown
- Update/replace note content
- Rename notes while preserving content
- Delete notes by title
- List notes with optional pattern filtering
- Markdown ↔ HTML conversion for Notes.app compatibility
- Support for headers, bold, italic, strikethrough, lists, links, code blocks, tables, checkboxes, and blockquotes
- Configurable account and folder via environment variables
- Performance tuning with LIMIT environment variable
- Full test suite for development validation
